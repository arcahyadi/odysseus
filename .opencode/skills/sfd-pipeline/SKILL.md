## What I do
- Walk the 7 canonical phases (CLASSIFY→KNOW→PLAN→BUILD→QUALITY→AUTOEVAL→MEMORY_OBSERVE)
- Spawn specialized agents per phase with appropriate models
- Store facts with provenance ([stated]/[observed]/[inferred])
- Apply user preferences (format, tone, language)
- Route responses to appropriate output modality (text, diagram, file)
- Classify data with 5 retention levels
- Filter protected content (never store SSN, health data, etc.)

## When to use me
Use this when the user makes a project request ("build a X", "create a Y", "deploy a Z").
The orchestrator agent (@sfd-orchestrator) will walk the phases automatically.
