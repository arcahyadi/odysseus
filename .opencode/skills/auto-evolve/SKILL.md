## What I do
- Analyze project outcomes to identify improvement areas
- Search the 60-tool registry for existing solutions
- Create custom skills/plugins/services when nothing exists
- Update the Obsidian second-brain with lessons learned
- Track system evolution over time

## When to use me
Automatically triggered after MEMORY_OBSERVE phase completes.
Can also be invoked explicitly: "evolve the system" or "improve agent os"

## Tools I use
- sfd-eventbus → read recent events and metrics
- sfd-discover → search tool registry
- sfd-memory → write lessons to memory
- web_search → find new tools and solutions
- mcp__obsidian__create_note → update second-brain

## Evolution metrics tracked
- Tools added this week
- Skills created this month
- Error rate before/after improvements
- Project completion time trend
- User satisfaction (from feedback events)
