# Guide Complet — Bonnes Pratiques Dev & Conception (Cycle de Vie Complet d'un Projet)

> Référence couvrant l'intégralité du cycle de vie d'un projet logiciel : de l'avant-projet à la maintenance et l'évolution post-livraison, avec la gestion de projet comme fil rouge transversal.

## Comment utiliser ce guide

Ce guide est **générique et modulaire** : il couvre le spectre complet, du développeur solo à la grande équipe. Aucune pratique listée ici n'est obligatoire dans tous les contextes — l'objectif est d'avoir la carte complète et de piocher ce qui est pertinent pour ta situation.

Repères utilisés dans tout le document :
- 🧍 **Solo / petite équipe (1-5)** — pratique à privilégier, souvent allégée
- 🏢 **Équipe moyenne/grande (5+)** — pratique supplémentaire qui devient nécessaire à l'échelle
- ⚠️ Point d'attention / erreur fréquente
- ✅ Checklist de fin de phase

Règle générale : **n'ajoute du process que quand la douleur qu'il résout devient réelle**. Trop de process tue un petit projet ; pas assez en tue un gros.
