# PARTIE 12 — CHECKLIST GLOBALE (vue condensée)

| Phase | Checklist condensée |
|---|---|
| Avant-projet | Besoin clarifié, charte validée, risques identifiés, budget estimé |
| Conception | Specs + critères d'acceptation, architecture documentée (ADR), maquettes validées |
| Setup | Repo + CI/CD + conventions + secrets externalisés |
| Développement | Tests écrits avec le code, review systématique, dette trackée |
| Gestion de projet | Cérémonies tenues, backlog priorisé, risques suivis |
| Qualité | DoD appliquée, recette signée, tests de charge faits |
| Déploiement | Versioning, changelog, rollback testé |
| Maintenance | Monitoring actif, incidents documentés, backups testés |
| Évolution | Mini-cycle par feature, feedback exploité, dette gérée |
| Culture | Onboarding < 1 jour, doc à jour, post-mortems sans blâme |
