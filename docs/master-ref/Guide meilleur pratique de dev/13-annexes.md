# ANNEXES

## A. Glossaire

- **ADR** : Architecture Decision Record — document court actant une décision technique structurante.
- **RACI** : Responsible, Accountable, Consulted, Informed — matrice de clarification des rôles.
- **MVP** : Minimum Viable Product — version minimale testable sur le marché.
- **SLA / SLO / SLI** : engagement contractuel / objectif interne / indicateur mesuré.
- **RTO / RPO** : délai de reprise / perte de données maximale acceptable après incident.
- **DoD / DoR** : Definition of Done / Definition of Ready.
- **WIP** : Work In Progress — travail en cours, limité en Kanban.
- **POC** : Proof of Concept — preuve de faisabilité technique à petite échelle.

## C. Références et concepts pour aller plus loin

- **The Twelve-Factor App** — principes pour des applications cloud-natives robustes.
- **C4 Model** — pour documenter une architecture à plusieurs niveaux de zoom.
- **DORA metrics / "Accelerate"** — mesurer la performance réelle d'une équipe tech.
- **Team Topologies** — organiser des équipes autour de la valeur livrée et de la loi de Conway.

- **WCAG** — référentiel d'accessibilité web.
