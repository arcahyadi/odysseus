# Agent OS — Second Brain (Obsidian Vault)

Ce vault est le second-brain d'Agent OS. Il est synchronisé avec le système via le MCP Obsidian.

## Structure

- `/topics/` — Connaissances par domaine (technologie, cuisine, projets...)
- `/areas/` — Projets et responsabilités en cours
- `/people/` — Contexte relationnel
- `/skills/` — Compétences acquises, patterns de succès

## Mémoire avec Provenance

Chaque fait est tagué :
- `[stated]` — l'utilisateur l'a dit explicitement
- `[observed]` — le système l'a constaté
- `[inferred]` — déduit avec niveau de confiance

## Auto-évolution

Le système recherche automatiquement les meilleurs skills, plugins et services.
Il peut aussi créer des solutions sur mesure quand rien n'existe.
